复跑基线 ​

在有 BW100、DTK、PyTorch 与 Triton 的 Linux 环境，从仓库根目录执行。使用新目录，确保每次输出独立。

bash
bash experiments/run_bw100_baseline.sh gfx936 ./bw100-repeat
bash experiments/run_bw100_lds_occupancy.sh gfx936 ./bw100-lds-occupancy-repeat
文件可核对的内容
environment.txt、source-sha256.txt采集时间、设备、工具链和送入容器的源文件校验值
e01.csv 与设备 ISA所有映射校验状态和逐轮有效拷贝带宽
e06-*.csv、e06-*-summary.txt 与设备 ISA尺寸、种子、间距、加载路径、时钟读数与独立 PMC
e07.txt 与设备 ISA指令吞吐与依赖链计时
e09-*.json、e09-*.s、e09-*-pmc.csv按配置 ID 对应的计时、正确性、Triton ISA 和独立 PMC。rocBLAS 通过实际 dispatch 名称识别
追加归档中的 e02.csv、e04.csv、*-pmc.csv 与设备 ISALDS 布局和独立加载链矩阵的逐轮计时、校验结果和分配置计数器

公开版 ISA 已清理本机路径及编译器内部地址。归档保留了采集时的文件 SHA-256；跨 Windows 与 Linux 检出时可用 LF 归一化清单比对。其他实验的历史记录和复测状态见 实验索引。

从原始数据生成图表 ​

实验页的 E01、E02、E04、E06 和 E09 图表由本档案的两个 ZIP 生成。在安装了 Matplotlib 和中文字体的环境中，从仓库根目录运行：

bash
python experiments/plot_bw100_baseline.py

字体未被识别时用 --font 指定字体文件。脚本仅读取归档，可在没有 DCU 的机器上运行。

跨代复测规则 ​

  • 保持形状、dtype、计时位置、codegen 参数、正确性阈值及样本统计方式一致。设备、驱动、DTK、频率策略、容器或框架改动分别记入环境记录。
  • 同一版本的 PMC 才直接比较原始计数。跨架构先对齐指标定义、单位与范围，再计算按指令、dispatch 或工作量归一化的值。
  • 新硬件和工具链同时升级时，记录组合差异。若两张卡都支持同一 DTK，再用同版工具链做跨硬件对照，条件允许时再补旧卡切换 DTK 的对照。
